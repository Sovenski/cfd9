## 3. era_pass rule (pre-committed constants, §A3)

```python
# src/pooled_validation.py
EMBARGO_NEST_BARS: int = max(STRUCTURAL_NEST)        # 200 — label look-ahead guard
MIN_STREAM_BARS:   int = 2 * max(STRUCTURAL_NEST)+1  # 401 — nest must fit
HOLDOUT_FRACTION:  float = 0.20                       # reserved tail of ref index
ERA_PASS_MIN_RATIO: float = 0.5                       # generalization floor

era_pass = (holdout_score > 0.0) and
           (holdout_score >= ERA_PASS_MIN_RATIO * mean(raw winner fold scores))
```

The mean is over the winner's RAW (unpenalized) informative fold scores
(`v17_acceptance.raw_fold_scores`). 0.5 is a generalization floor: the holdout
may be one regime; demanding parity with the search mean would be stricter than
fold-to-fold variance justifies. Empty fold basis → mean 0.0 → any positive
holdout score passes (the LCB is 0 there anyway). The holdout verdict fills
`era_pass` UNLESS the caller passed an explicit value (explicit always wins —
`_effective_era_pass`, pinned by test). Holdout boundary: reference-index bar at
`active` (first reserved bar) + 200-bar embargo; per-stream slices get standalone
per-slice `add_pivot_labels` warm-up exactly like every fold slice.

## 4. winner_variant rule (§B2, `select_winner_variant`)

```
key = (bool(acceptance.era_pass), float(final_lcb_deflated));  winner = max(variants, key)
```

- **era_pass FIRST**: a holdout-passing variant always beats a failing one —
  generalization to the selection-untouched tail outranks any in-search number.
- **Then deflated LCB** breaks ties within the same pass class (the honest
  headline for a batched search).
- `era_pass=None` (holdout never evaluated) counts as **False**; exact ties keep
  the FIRST declared variant (dict insertion order — `"baseline"` first by
  convention), so the rule is deterministic. Empty dict raises `ValueError`.
- `out["winner_variant"] = {side: name}`; top-level `out["sides"][side]` is the
  winning variant's per-side dict.

